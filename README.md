## Project

**Bidding-Language Restrictions and the Price of Anarchy**

How does market efficiency change when generators cannot express their true
costs through the permitted bids? The main comparison is between block-form true
costs with expressive block bids and the same costs with quadratic-only bids.

See the [project brief](project/README.md) for the controlled comparison, modelling
decisions, and scope.

## Working together

- Use GitHub Issues to agree tasks and ownership, and small branches and pull
  requests for changes.
- Keep original course PDFs unchanged. Put shared project notes in Markdown so
  changes can be reviewed and merged.
- Use lowercase, hyphenated filenames with zero-padded weeks, such as
  `week-06-slides.pdf` and `week-06-tasks.pdf`.
- Keep one canonical copy of each document; do not add `final-v2` duplicates.
- Do not add PowerPoint files or the retired exercise scripts. Project code can
  be introduced once the modelling and implementation plan is agreed.
- Add paper PDFs only when sharing is permitted. Otherwise, add a citation and
  access link to the [reference guide](references/README.md).

## Access and publication

Keep the repository private until permission to publish the course materials
and their historical versions is confirmed. Removing a file from the current
layout does not remove it from Git history.

The repository owner manages collaborator invitations. Licensed publisher
downloads are not included in the shared repository; team members should obtain
them through the access links using their own authorized access.
