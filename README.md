## Project

**Bidding-Language Restrictions and the Price of Anarchy**

The project compares quadratic-only bidding under quadratic versus block-form
true costs. It studies worst-CCE production-cost inefficiency and valid PoA
bounds, without a mismatch-severity sweep.

See the [project brief](project/README.md) for the controlled comparison, modelling
decisions, and scope, and the [work plan](project/work-plan.md) for delivery
milestones and report requirements.

## Working together

- Use GitHub Issues to agree tasks and ownership, and small branches and pull
  requests for changes.
- Keep original course PDFs unchanged. Put shared project notes in Markdown so
  changes can be reviewed and merged.
- Use lowercase, hyphenated filenames with zero-padded weeks, such as
  `week-06-slides.pdf` and `week-06-tasks.pdf`.
- Keep one canonical copy of each document; do not add `final-v2` duplicates.
- Do not add PowerPoint files or the retired exercise scripts. Keep new project
  code focused on the agreed model and validate each stage before expanding it.
- Add paper PDFs only when sharing is permitted. Otherwise, add a citation and
  access link to the [reference guide](references/README.md).

## Access and publication

This repository is public. Add materials only when you are authorized to share
them publicly. Removing a file from the current layout does not remove it from
Git history.

The repository owner manages collaborator invitations. Shared paper PDFs require
permission for public redistribution; the [reference guide](references/README.md)
lists available copies and publisher access links.
