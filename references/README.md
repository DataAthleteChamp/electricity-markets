# References

Shared background material for the course and the
[bidding-language project](../project/README.md).

## Course algorithm notes

[Algorithm explanation](algorithm-explanation.pdf)

*Electricity Markets as Games: Bounding the Price of Anarchy* is a seven-page
course note explaining the market model, generalized smoothness, and a
constraint-generation algorithm for a PoA bound.

The construction uses admissible scaled-truthful deviations. It is not
automatically a valid bound for a bidding language that cannot represent the
true costs; that requires a new argument with feasible deviations.

## Research paper

**Marcel Sole Avila, Razgar Ebrahimy, and Georgios Tsaousoglou (2025).**
*How Inefficient Can An Electricity Market Be?*
2025 IEEE Kiel PowerTech, pp. 1-6.

- [Publisher DOI](https://doi.org/10.1109/PowerTech59965.2025.11180517)
- [DTU publication record](https://orbit.dtu.dk/en/publications/how-inefficient-can-an-electricity-market-be/)

The paper studies worst-case equilibrium inefficiency across generators' true
cost functions. It is useful background, not a result establishing the effect of
the cost/bid-language mismatch in our project.

The [paper PDF](how-inefficient-can-an-electricity-market-be.pdf) is included in
the repository. The repository owner has confirmed permission to share this
copy publicly; this does not establish permission to redistribute other papers.
